/*/ Best practices for naming a folder in js project.\*\

✅ 1. Use lowercase letters
✅ 2. Use hyphens to separate words
✅ 3. Name folders based on content or function
✅ 4. Avoid special characters or spaces
✅ 5. Use plural for folders that contain multiple items

/*/ Best Practices for naming a file. \*\

✅ Best Practices for Naming Files in JavaScript
1. Use lowercase letters

2. Use hyphens to separate words

3. Be descriptive and specific
File names should describe what the file does or contains.

✅ fetch-users.js

✅ calculate-discount.js

❌ stuff.js

❌ data.js

4. Use .js or .mjs extensions
Use .js for most JavaScript files.

Use .mjs if you're explicitly using ES Modules in Node.js.

5. React Component Files (if using React)
Use PascalCase for components.

✅ UserProfile.js

✅ DoctorCard.js

6. Group related files logically

7. Avoid using file names that clash with core libraries
Avoid naming files like fs.js, http.js, or events.js to prevent confusion.

/*/ The general rules for constructing names for variables (unique identifiers) are: \*\

Names can contain letters, digits, underscores, and dollar signs.
Names must begin with a letter.
Names can also begin with $ and _ (but we will not use it in this tutorial).
Names are case sensitive (y and Y are different variables).
Reserved words (like JavaScript keywords) cannot be used as names.


/*/ JavaScript Function Syntax \*\
A JavaScript function is defined with the "function" keyword, followed by a "name", followed by parentheses "()".

Function names can contain letters, digits, underscores, and dollar signs (same rules as variables).

The parentheses may include parameter names separated by commas:
(parameter1, parameter2, ...)

The code to be executed, by the function, is placed inside curly brackets: {}
